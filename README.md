# SAT Coach

An adaptive practice coach for the **Digital SAT**. It gives you short sessions of math and Reading & Writing questions, explains every answer in the style of the official College Board answer explanations, tracks which skills you struggle with, and keeps bringing those back until they stick. After each session you get a projected score so you can see your progress.

- **Questions modeled on real ones.** New questions are generated by an LLM using retrieved real examples (RAG), then checked automatically before you ever see them.
- **Real articles.** Reading & Writing sets are written about real published texts: public-domain literature, historical speeches, and open-access science, the same kinds of sources the SAT uses.
- **Coaching, not just quizzing.** Each session puts about 60% of its questions on your weakest skills and includes spaced review of questions you missed.
- **Free to run.** The default generator is Google Gemini's free tier. Without any API key, the app still works from its built-in question bank.

## Quick start

Requires Python 3.11+.

```bash
git clone https://github.com/ridwankhan-rsk/sat_coach.git
cd sat_coach
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[pdf]"
cp .env.example .env     # then paste a free key from https://aistudio.google.com/apikey into GEMINI_API_KEY
sat-coach init           # create the database and load the seed question bank
sat-coach serve          # open http://127.0.0.1:8000
```

Pick or create a profile, then start the **baseline session**.

## How a session works

| | Math | Reading & Writing |
|---|---|---|
| **Baseline** (first session) | 8 questions, 2 from each domain, 3 easy / 3 medium / 2 hard | 1 article, 5 questions covering all 4 domains |
| **Adaptive** (after that) | ~5 on your weakest skills, ~1 spaced review, the rest for coverage | 1 article, questions on your weakest skill in each domain, plus 1 review item when one is due |

After you submit:
- every question shows your answer, the correct answer, and why each choice is right or wrong ("Choice B is the best answer because…")
- for each miss you can tag **why** it happened: didn't know how, careless mistake, or ran out of time
- your **projected score** (Math + R&W, 400–1600, with a ± range) updates and is charted on the Progress page

Every question card is tagged **Original** (the seed set), **Official** (your imported PDFs) or **Generated**. Generated variants of questions you missed are tagged **Generated · variant**.

The **Insights** page shows what the coach knows about you: a skill-by-difficulty accuracy table, your most-missed questions, and the review queue.

### Under the hood

- **Taxonomy** (`sat_coach/taxonomy.py`): the official Digital SAT domains and skills, with their section weights.
- **Mastery** (`coach/mastery.py`): a per-skill ability estimate (an Elo / 1-parameter IRT model). Each new question is pitched at a difficulty you have roughly a 65–70% chance of answering correctly.
- **Spaced review** (`coach/review.py`): a missed question comes back next session. Each time you get it right, it waits longer (1 → 2 → 4 → 8 sessions). Miss it again and it returns to the start. Once a question is due again after you got it right, you get a newly generated variant of it ("similar to what you missed") instead of the same question.
- **Projected score** (`coach/scoring.py`): skill abilities are combined into domain abilities, weighted by each domain's share of the test, and mapped to 200–800 per section. The ± range narrows as you answer more questions. It is an estimate from practice data, **not an official score**.
- **Generation** (`gen/`): retrieve 3–4 exemplars for the skill (your imported official questions first, then the seed set), batch-generate questions, then validate them:
  1. schema checks (4 distinct choices, a rationale for every choice)
  2. for math, a **sympy** computation of the keyed answer
  3. a **blind re-solve** by a separate model call that must agree with the key

  Only questions that pass are saved. Generated questions are cached in SQLite and reused, so a session usually costs only a few API calls.

## Commands

```bash
sat-coach serve [--host 0.0.0.0]  # web app; use 0.0.0.0 to let another device on your Wi-Fi join
sat-coach fetch-passages          # download more real passages (Project Gutenberg + PLOS open access)
sat-coach generate --math 12 --rw-sets 2   # pre-generate questions so sessions start instantly
sat-coach import-pdfs ~/Downloads/sat     # import official practice PDFs you downloaded (see below)
sat-coach stats "Ana"             # projected score and weakest skills for a profile
sat-coach bank                    # how many questions are original / official / generated
sat-coach bank --origin generated --section math   # list the generated questions
sat-coach preview "Ana"           # what Ana's next session will contain and which questions it will generate
sat-coach users add "Ana" / sat-coach users list
```

## Choosing a model

| Provider | Setup | Notes |
|---|---|---|
| **Gemini** (default) | `GEMINI_API_KEY` from [Google AI Studio](https://aistudio.google.com/apikey) | Free tier. It has per-minute and per-day request limits, and the app retries automatically when it hits them. Google may use free-tier prompts to improve its models, which is harmless for SAT questions but worth knowing. `GEMINI_MODEL` defaults to `gemini-flash-latest`. |
| **Claude** (optional) | `pip install -e ".[claude]"`, `LLM_PROVIDER=claude`, `ANTHROPIC_API_KEY` | Paid. Higher-quality generation. |
| **None** | no key | Works offline from the seed bank and any questions already generated. |

## Data sources and copyright

- **Seed bank** (`data/seed/`): 38 original math questions and 20 Reading & Writing questions, written for this project, about 4 public-domain texts (Austen, Lincoln, Darwin, Thoreau). MIT licensed along with the code.
- **Fetched passages**: Project Gutenberg texts (public domain in the US) and PLOS article abstracts (CC BY 4.0). Each passage is shown with its source and license.
- **Official College Board material** (Bluebook practice tests, the SAT Question Bank, answer explanations) is copyrighted. This repo does **not** include or redistribute it. `sat-coach import-pdfs` lets you use PDFs **you downloaded yourself** for your own practice and as generation examples. They're stored in `data/private/`, which is gitignored. Khan Academy content is not scraped; its terms don't allow it.

## Development

```bash
pip install -e ".[dev,claude,pdf]"
pytest
```

Tests run offline with a fake LLM. They cover:
- answer validation, including rejection of unsafe sympy input
- mastery updates and score bounds
- session blueprints (domain coverage, weak-skill targeting)
- the review schedule
- profile isolation
- the generate → validate pipeline

## Roadmap

- Hosted version with real accounts: Postgres + pgvector, a hosted auth provider, a server-side API key with per-user quotas. Every progress table already carries `user_id`.
- Quantitative evidence, cross-text, and rhetorical synthesis question types (they need charts, paired texts, or notes rather than one article).
- A Desmos calculator embed for math.
- Timed modules that mirror the real test's adaptive second module.
